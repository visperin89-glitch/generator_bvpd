Як увімкнути функції штучного інтелекту (ШІ)?
Оскільки файл працює локально на вашому комп'ютері, для роботи ШІ потрібен особистий безкоштовний ключ доступу:
  1. Перейдіть на сайт aistudio.google.com (увійдіть через Google-акаунт).
  2. Натисніть кнопку "Create API key" (Створити API ключ).
  3. Скопіюйте згенерований ключ та вставте його у вікні «Налаштування ШІ» вгорі або при натисканні «✨ Офіційно» / «📝 Коректор».
Ключ зберігається лише у вашому браузері і нікуди не передається. Скинути налаштування ключа.
