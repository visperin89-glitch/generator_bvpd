# generator_bvpd

Вебдодаток **«Генератор документів на БВПД»** для щоденної роботи юристів системи надання безоплатної правничої допомоги.

## Основні можливості
- Автоматичне формування та попередній перегляд документів у форматі `.docx` (ДСТУ, Times New Roman):
  - **Заява** про надання безоплатної вторинної правничої допомоги (особисте звернення та через представника);
  - **Талон** про прийняття заяви;
  - **Накази** (на адвоката та на працівника) із вшитим Державним Гербом України;
  - **Службові листи** (на адвоката та на працівника).
- Автоматичне відмінювання ПІБ українською мовою (`shevchenko`).
- Модуль розрахунку доходів для малозабезпечених осіб (простий та розширений розрахунок за Методикою Мін'юсту № 1445/5).
- Локальний ШІ-помічник (Gemini API) з анонімізацією персональних даних клієнта.
- Імпорт/експорт профілю клієнта (JSON) та підтримка світлої/темної теми.
